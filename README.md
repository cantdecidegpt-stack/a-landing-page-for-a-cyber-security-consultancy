## What this is

A static, responsive landing site: one HTML file, one stylesheet, one small script.
No framework, no build step and no external requests.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy free

- **GitHub Pages**: push this folder to a public repo, Settings -> Pages -> deploy from branch.
- **Cloudflare Pages**: create a project, upload the folder.
- **Netlify**: drag the folder into app.netlify.com/drop.

## Files

- `index.html` - landing page
- `styles.css` - all styling
- `app.js` - navigation, form and reveal animations
- `content.json` - the copy and structure as data
- `site.json` - metadata used by the BotLancer delivery check
